# src/render/

**Ownership**: WS-B (renderer-anytime)

This module implements the rendering pipeline for the GFL visual demo, focusing on the WebGL raymarcher, anytime budget system, and structural Level of Detail (LOD). It provides the core mechanisms to translate computational budgets into real-time rendering constraints, demonstrating the relationship between available resources and representation complexity (steps 5, 8, 9, 11, 16, 17, 18).
